# 🎵 اتاق موسیقی مشترک (Sync Music Rooms)

یه سایت ساده که باهاش می‌تونی با دوستت هماهنگ به موسیقی گوش بدی:

- یه نفر **اتاق می‌سازه** و یه **کد ۵ حرفی** می‌گیره.
- نفر بعدی با اون **کد وارد اتاق می‌شه**.
- هر کدوم (فرقی نمی‌کنه هاست باشه یا مهمون) می‌تونه **لینک آهنگ** بذاره — لینک مستقیم MP3 یا لینک یوتیوب.
- **پلی / پاز / جابه‌جایی زمان** برای هر دو نفر هماهنگ می‌شه.

## اجرای لوکال

نیاز به Node.js نسخه ۱۸ به بالا داری.

```bash
npm install
npm start
```

بعد برو به `http://localhost:3000`. برای تست، یه تب اتاق بساز و توی یه تب دیگه (یا مرورگر دیگه) با کد وارد شو.

## دیپلوی آنلاین

چون هماهنگ‌سازی نیاز به سرور دائمی داره، از سرویس‌هایی مثل **Render** یا **Railway** استفاده کن (نه Netlify/Vercel که فقط استاتیک هستن).

### Render
1. کد رو روی یه ریپوی GitHub بذار.
2. توی Render یه **Web Service** جدید بساز و ریپو رو وصل کن.
3. تنظیمات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Render خودش پورت رو از طریق متغیر `PORT` می‌ده و سرور اونو می‌خونه.

### Railway
1. ریپو رو وصل کن یا با `railway up` آپلود کن.
2. Railway به‌صورت خودکار `npm install` و `npm start` رو اجرا می‌کنه.

## نکته‌ها

- **لینک MP3** باید مستقیم و قابل دسترس باشه (مثلاً روی یه هاست که CORS اجازه بده). خیلی از هاست‌ها پخش مستقیم از دامنه‌ی دیگه رو محدود می‌کنن.
- **یوتیوب**: هر لینک استاندارد یوتیوب (watch، youtu.be، shorts، embed) کار می‌کنه.
- برای اولین پخش، مرورگر ممکنه به‌خاطر سیاست autoplay نیاز به یه کلیک کاربر داشته باشه — اگه پخش نشد یه بار روی صفحه کلیک کن.
- وضعیت اتاق‌ها در حافظه‌ی سرور نگه‌داری می‌شه؛ با ری‌استارت سرور اتاق‌ها پاک می‌شن.

## ساختار فایل‌ها

```
package.json      # وابستگی‌ها و اسکریپت‌ها
server.js         # سرور Express + Socket.IO و منطق هماهنگ‌سازی
public/
  index.html      # صفحه‌ی اصلی
  style.css       # استایل
  app.js          # منطق سمت کلاینت (پلیر و سوکت)
```
